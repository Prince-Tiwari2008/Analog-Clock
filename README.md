# 🕒 Analog Clock
A modern and visually appealing Analog Clock built using **HTML, CSS, and Vanilla JavaScript**. It displays real-time hours, minutes, and seconds through dynamically rotating clock hands with a clean, minimal, dark-themed interface.

## ✨ Features :-
- **Real-Time Clock:** Automatically updates according to the system's current time.
- **Dynamic Clock Hands:** Displays hour, minute, and second hands with accurate rotation.
- **Modern UI:** Clean, minimal, and elegant dark-themed design.
- **CSS Styling:** Uses CSS transforms and positioning to create the analog clock.
- **Lightweight:** Built using pure HTML, CSS, and JavaScript without external libraries.

## 🛠️ Technologies Used :-
- **HTML5** – Structure of the clock.
- **CSS3** – Styling, layout, positioning, and visual effects.
- **JavaScript (Vanilla JS)** – Clock functionality and real-time updates.

## ⚙️ How It Works :-
1. JavaScript's Date() object retrieves the current system time.
2. getHours(), getMinutes(), and getSeconds() extract the time values.
3. Mathematical calculations determine the rotation angles of each clock hand.
4. CSS transform: rotate() dynamically rotates the hands.
5. setInterval() updates the clock every second.
